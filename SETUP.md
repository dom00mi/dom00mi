# Setup

1. Create a **public** GitHub repository named `dom00mi` under the `dom00mi` account.
2. Upload `README.md`, the entire `pages/` directory, and the entire `assets/` directory to its root. Preserve the paths.
3. The profile README will display automatically at `https://github.com/dom00mi`.
4. Click each category banner to confirm it opens the correct page.
5. Replace category placeholders with verified direct links to your individual repositories as desired.
6. Keep individual project code in its existing repositories; these pages act as an index, not duplicates.

The SVG banners are committed directly to the repository and require no external image host. GitHub activity badges in the main README use external services and may occasionally be unavailable.

## Add a new repository to a category page

Open `pages/mathematics.md` (or another category file) and insert:

```md
- **[Stochastic Calculus Notes](https://github.com/dom00mi/your-repo)** — Derivations and numerical examples.
```

For a PDF stored in this portfolio repository, create `documents/` and add:

```md
[View the presentation (PDF)](../documents/your-presentation.pdf)
```

For a PDF in another repository, use its full GitHub URL. For an image stored here, use `![Description](../assets/your-image.png)` from a category page.

SVG banners are in `assets/`; you can replace them with your own PNG/JPG images, but update their paths in both the main README and the category pages. The illustrative images previously shown in chat are not identical to these locally created SVG banners.

# Private Research & Collaboration

Some research projects, notebooks and implementations are not publicly listed. If you are interested in a particular topic, please [email me](mailto:domenico.nava.dn@gmail.com) or contact me through [GitHub](https://github.com/dom00mi). I can discuss the project and, where appropriate, grant repository access.

## Option A — View in your browser (no SSH key)

1. Send me your **GitHub username** and the project you would like to view.
2. I can invite your GitHub account to the relevant private repository.
3. Accept the GitHub invitation and sign in to view the repository on github.com.

**Important:** On a personal-account private repository, collaborator access generally includes write permissions; a true read-only role is available for repositories owned by a GitHub organisation. Access is always granted at my discretion.

## Option B — Clone and collaborate

Once your invitation is accepted, you can clone via **HTTPS** without setting up SSH:

```bash
git clone https://github.com/dom00mi/REPOSITORY_NAME.git
```

Or, for SSH access, create a key on your own machine:

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

Add the **public** key (`~/.ssh/id_ed25519.pub`) in **GitHub → Settings → SSH and GPG keys → New SSH key**. Then clone:

```bash
git clone git@github.com:dom00mi/REPOSITORY_NAME.git
```

Never share your private key. SSH keys authenticate your GitHub account; they do **not** replace a repository invitation.

## For automated systems

Deploy keys can be configured by the repository owner under **Repository Settings → Deploy keys** for a server or CI system. These are different from human collaborator invitations.

[GitHub documentation: Inviting collaborators](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/managing-people-and-teams-with-access-to-your-repository/inviting-collaborators-to-a-personal-repository) · [SSH setup](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)
